# posts/

Drop a `.md`, `.ipynb`, `.html` or `.pdf` file here and it is published as a
blog post on the next push. A folder containing one of those plus its assets
works too.

Naming a file `YYYY-MM-DD-slug.ext` sets the date and the URL. Everything else
— title, summary, tags — is inferred, and can be overridden with front matter
or a `<name>.meta.yml` sidecar.

Full reference: [../README.md](../README.md). This file is ignored by the build.
